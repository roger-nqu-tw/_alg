# 演算法遞迴關係式與閉合公式驗證

本專案透過 Python 實作四種經典的演算法時間複雜度遞迴關係，並驗證其迭代計算結果與數學閉合公式（Closed-form Formula）是否相符。同時列出各關係式對應的 Big-O 漸進時間複雜度。

## 核心功能

程式碼分為兩個主要部分：

1. **迴圈模擬遞迴 (`T1` ~ `T4`)**：將原本的遞迴函式改寫為迴圈（Iterative）形式，由 Base case $T(1)=1$ 開始往上推算，避免過深遞迴導致的 Stack Overflow 效應。
2. **閉合公式驗證 (`formula1` ~ `formula4`)**：直接使用數學解出的公式進行 $O(1)$ 運算，並與迴圈模擬的結果進行比對。

## 遞迴關係式詳解

| 編號 | 遞迴關係式 | Base Case | 閉合公式 (Closed-form) | 時間複雜度 | 常見演算法情境 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | $T(n) = T(n-1) + 8$ | $T(1) = 1$ | $T(n) = 8n - 7$ | $O(n)$ | 單層迴圈遍歷 (如線性搜尋) |
| **2** | $T(n) = 2T(n-1) + 9$ | $T(1) = 1$ | $T(n) = 10 \times 2^{n-1} - 9$ | $O(2^n)$ | 暴力枚舉、費氏數列純遞迴 |
| **3** | $T(n) = 2T(n/2) + 1$ | $T(1) = 1$ | $T(n) = 2n - 1$ | $O(n)$ | 走訪滿二元樹的所有節點 |
| **4** | $T(n) = T(n/2) + 1$ | $T(1) = 1$ | $T(n) = \lfloor\log_2 n\rfloor + 1$ | $O(\log n)$ | 二元搜尋法 (Binary Search) |

*(註：公式 3 與 4 的前置假設為 $n$ 是 2 的冪次方)*

## 程式碼結構說明

*   **`T1(n)` / `formula1(n)`**：線性遞迴。每次處理減少 1 個規模，並花費常數時間 8。
*   **`T2(n)` / `formula2(n)`**：指數遞迴。每次處理分裂成 2 個子問題，規模各減 1，導致運算量呈指數爆炸。
*   **`T3(n)` / `formula3(n)`**：分治法 (Divide and Conquer)。規模減半，但分裂成 2 個子問題。根據 Master Theorem，其複雜度為 $O(n)$。
*   **`T4(n)` / `formula4(n)`**：對數遞迴。規模減半，且只有 1 個子問題。Python 中的 `n.bit_length()` 剛好等同於 $\lfloor\log_2 n\rfloor + 1$。
