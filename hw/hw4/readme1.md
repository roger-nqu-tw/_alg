# 固定點迭代法 (Fixed-Point Iteration) 分析

這份文件分析了一段尋找 $\sqrt{3}$（約為 1.73205）近似值的 Python 程式碼。雖然三個函數的目標完全相同，但它們在迭代過程中的**收斂行為（Convergence）**和**速度**卻有天壤之別。

## 原始程式碼

```python
f1 = lambda x: 3 / x
f2 = lambda x: x - 1 / 4 * (x * x - 3)
f3 = lambda x: 1 / 2 * (x + 3 / x)

x1 = x2 = x3 = 1

for i in range(20):
    x1, x2, x3 = f1(x1), f2(x2), f3(x3)
    print(f'x1: {x1:.5f} | x2: {x2:.5f} | x3: {x3:.5f}')
```

## 1. 核心概念：為什麼是在找 $\sqrt{3}$？

迭代法的核心概念是透過不斷將前一次的輸出作為下一次的輸入（即 $x_{n+1} = f(x_n)$），期望最終數值會穩定在一個常數 $x$ 上。當數值不再變動時，這個點稱為**不動點（Fixed Point）**，滿足方程式 $x = f(x)$。

我們將這三個函數設為 $x = f(x)$ 來解方程式：

* **`f1`**: 
  $$x = \frac{3}{x} \implies x^2 = 3 \implies x = \pm\sqrt{3}$$
* **`f2`**: 
  $$x = x - \frac{1}{4}(x^2 - 3) \implies \frac{1}{4}(x^2 - 3) = 0 \implies x^2 = 3 \implies x = \pm\sqrt{3}$$
* **`f3`**: 
  $$x = \frac{1}{2}\left(x + \frac{3}{x}\right) \implies 2x = x + \frac{3}{x} \implies x = \frac{3}{x} \implies x^2 = 3 \implies x = \pm\sqrt{3}$$

這三個函數的不動點都是 $\sqrt{3}$。

---

## 2. 三個函數的執行結果與分析

如果實際執行迴圈，會觀察到三種截然不同的現象：

### ❌ `f1`：無窮震盪（無法收斂）
* **公式**： $x_{n+1} = \frac{3}{x_n}$
* **過程**： $1 \to 3 \to 1 \to 3 \dots$
* **分析**： 數值會永遠在 1 和 3 之間跳動。這是一個**失敗的迭代設計**，因為它無法逼近真正的答案。

### ⚠️ `f2`：線性收斂（速度普通）
* **公式**： $x_{n+1} = x_n - \frac{x_n^2 - 3}{4}$
* **過程**： $1 \to 1.5 \to 1.6875 \to 1.7255 \to 1.7312 \dots$
* **分析**： 這個函數會逐步逼近 $\sqrt{3}$。雖然每次都會更接近答案一點，但需要較多次的迴圈才能達到高精確度。

### ✅ `f3`：二次收斂（極度快速 —— 牛頓法）
* **公式**： $x_{n+1} = \frac{1}{2}\left(x_n + \frac{3}{x_n}\right)$
* **過程**： $1 \to 2.0 \to 1.75 \to 1.73214 \to 1.73205 \dots$
* **分析**： 這是著名的**牛頓法（Newton-Raphson Method）**應用於求解 $x^2 - 3 = 0$ 的結果。大約只需 4 到 5 次迭代，就能達到小數點後 5 位的極高精確度，收斂速度呈幾何級數暴增。

---

## 3. 數學原理：為什麼收斂速度差這麼多？

判斷迭代法 $x_{n+1} = f(x_n)$ 能否收斂，取決於函數在不動點（$x^* = \sqrt{3}$）的**一階導數絕對值 $|f'(x^*)|$**：

1. **$|f'(x^*)| > 1$**：發散（越跑越遠）。
2. **$|f'(x^*)| = 1$**：邊界情況，通常會震盪（如 `f1`）。
3. **$0 < |f'(x^*)| < 1$**：線性收斂（如 `f2`）。數字越小，收斂越快。
4. **$|f'(x^*)| = 0$**：二次（或更高階）收斂，極度快速（如 `f3`）。

### 導數計算驗證：

* **`f1` 的導數**： 
  $$f_1'(x) = -\frac{3}{x^2}$$
  代入 $\sqrt{3}$，得到 $f_1'(\sqrt{3}) = -1$。絕對值為 1，導致**震盪**。

* **`f2` 的導數**： 
  $$f_2'(x) = 1 - \frac{x}{2}$$
  代入 $\sqrt{3}$，得到 $1 - \frac{1.732}{2} \approx 0.134$。因為 $0.134 < 1$，所以**穩定收斂**。

* **`f3` 的導數**： 
  $$f_3'(x) = \frac{1}{2}\left(1 - \frac{3}{x^2}\right)$$
  代入 $\sqrt{3}$，得到 $\frac{1}{2}(1 - 1) = 0$。導數為 0 代表進入了**超快速收斂（牛頓法）**的領域。

> **💡 結論**：這段程式碼完美示範了在撰寫演算法時，**「數學模型的選擇」比「迴圈執行的次數」更能決定程式的效能**。
