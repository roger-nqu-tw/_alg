# 使用迭代法尋找黃金比例 (Golden Ratio)

這是一個極其簡單、但非常經典的數值分析例子，展示如何透過**固定點迭代法 (Fixed-Point Iteration)** 來尋找自然界中的完美比例——黃金比例。

## 1. 問題情境與數學模型

黃金比例（大約是 1.618）在數學上滿足以下方程式：
$$x^2 = x + 1$$

為了解出這個方程式，我們不需要背誦公式解。我們可以將方程式兩邊同除以 $x$，做個簡單的移項，轉換為迭代函數的形式：
$$x = 1 + \frac{1}{x}$$

這形成了一個非常單純的迭代函數 $f(x)$：每次只要把前一個數字「取倒數，然後加 1」，當作新的輸入值即可。

## 2. Python 實作程式碼

這個實作完全不需要複雜的數學函式庫，只需要最基本的加法與除法。

```python
# 定義極簡的迭代函數: x = 1 + 1/x
g = lambda x: 1 + 1 / x

# 初始猜測值設為 1.0
x = 1.0

# 進行 10 次迭代
print(f"{'次數':<4} | {'產生的 x 值':<12}")
print("-" * 22)
for i in range(1, 11):
    x = g(x)
    print(f"{i:<4} | {x:.6f}")
