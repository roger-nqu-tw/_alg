## 第一階段：數學基礎危機與「可計算性」的定義（第 01–04 章）

| 章節主題 | 人物與核心概念 | 在計算理論中的關鍵意義 |
| :--- | :--- | :--- |
| **01-希爾伯特的問題** | **大衛·希爾伯特（David Hilbert）**<br>形式主義與判定性問題 | 1900 年提出數學完全形式化綱領，追問是否存在一套「機械化程序」能判定所有數學命題的真偽，催生了計算機科學的源頭問題。 |
| **02-哥德爾的定理** | **庫爾特·哥德爾（Kurt Gödel）**<br>不完備定理與哥德爾編碼 | 1931 年證明任何包含基本算術的一致性公理系統，都存在「既無法證明也無法證偽」的命題，宣告希爾伯特的絕對完備夢想無法實現。 |
| **03-丘奇的函數** | **阿隆佐·丘奇（Alonzo Church）**<br>$\lambda$ 演算（Lambda Calculus） | 從「純函數定義與代換」的角度刻劃可計算性，成為現代函數式程式語言（Lisp、Haskell 與 Python `lambda`）的理論基石。 |
| **04-圖靈的機器** | **艾倫·圖靈（Alan Turing）**<br>圖靈機與停機問題 | 以「無限紙帶＋讀寫頭＋狀態轉移」建立抽象計算模型，提出通用圖靈機（儲存程式概念），並證明停機問題（Halting Problem）不可判定。 |

## 第二階段：形式語言、計算複雜度與實體電腦（第 05–08 章）

- **05-喬姆斯基的語法**：諾姆·喬姆斯基（Noam Chomsky）提出形式語言層級（Chomsky Hierarchy），將文法由弱到強分為四類，並精準對應到四種抽象計算機器：
  1. 正則文法（Regular）$\leftrightarrow$ 有限狀態機（FSM）
  2. 上下文無關文法（Context-Free）$\leftrightarrow$ 下推自動機（PDA，現代程式語言剖析器的基礎）
  3. 上下文有關文法（Context-Sensitive）$\leftrightarrow$ 線性有界自動機（LBA）
  4. 無限制文法（Recursively Enumerable）$\leftrightarrow$ 圖靈機（Turing Machine）

  > 在上圖中，最內圈的 regular（正則語言）表達能力最受限，卻最容易高效剖析；最外圈的 recursively enumerable（遞迴可枚舉語言）則等價於圖靈機所能識別的所有語言——這張圖正好銜接了第 04 章的機器模型與第 05 章的語法理論。

- **06-庫克的證明**：史蒂芬·庫克（Stephen Cook）提出庫克-列文定理（Cook–Levin Theorem），證明布林可滿足性問題（SAT）為第一個 NP-Complete（NP 完全）問題。這標誌著計算理論從「能不能算（可計算性）」跨入「算得快不快（計算複雜度，$P$ 與 $NP$ 問題）」。
- **07-馮紐曼的報告**：約翰·馮紐曼（John von Neumann）撰寫《EDVAC 報告書初稿》，將圖靈的「通用圖靈機」與布林邏輯轉化為實際可建造的硬體藍圖（運算器、控制器、記憶體與 I/O），確立「程式與資料同存於記憶體」的現代電腦架構。
- **08-從語言到機器**：總結全書主線，說明人類撰寫的高階程式語言，如何經由詞法分析、語法剖析與編譯／直譯技術，一步步轉譯成馮紐曼架構硬體能執行的機器指令。
