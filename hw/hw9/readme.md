# 經典搜尋演算法實作與應用

本專案示範了如何使用不同的搜尋演算法解決電腦科學中的五個經典問題，涵蓋了從基礎路徑尋找、狀態空間探索，到硬體設計層級的應用。

## 演算法說明與應用場景

### 1. 深度優先搜尋 (DFS)
*   **特性**：優先往單一方向深入探索，直到撞牆或到達目標後才退回上一步 (Backtracking)。
*   **記憶體佔用**：較低，僅需記錄當前路徑。
*   **應用場景**：
    *   **老鼠走迷宮問題**：不斷往前試探，遇到死胡同就退回。
    *   **八皇后問題**：一行一行放置皇后，若發現衝突便拔起當前皇后，回溯到上一行重新放置。

### 2. 廣度優先搜尋 (BFS)
*   **特性**：以同心圓的方式向外擴展，先探索距離起點近的節點，保證找到的是「最少步數」的解。
*   **記憶體佔用**：較高，需要 Queue 來儲存同一深度的所有可能狀態。
*   **應用場景**：
    *   **狼羊甘藍菜過河問題**：過河是一種「狀態轉移」，BFS 可以找出最少趟數的安全過河策略。

### 3. 啟發式搜尋 (A* Search)
*   **特性**：結合了 Dijkstra 演算法 (考量實際代價) 與 Greedy Best-First Search (考量預估代價) 的優點。透過公式 `f(n) = g(n) + h(n)` 來決定下一步。
*   **應用場景**：
    *   **NPC 搜尋玩家問題**：在遊戲地圖中，NPC 需要快速且聰明地找到玩家，A* 可以大幅減少盲目搜尋的面積。

### 4. 領域特定演算法 (以 BFS/A* 為基礎)
*   **IC 設計電路繞線 (Routing)**：
    *   **Lee Algorithm**：本質上是將網格化的電路板使用 BFS 向外擴展，保證找到起點到終點的最短路徑。
    *   **進階應用**：現代 EDA 工具會結合 A* 與線網權重，以解決多層板、擁擠度 (Congestion) 與時序 (Timing) 限制等複雜問題。
